# Le Mie Pietanze Dolci

A React-based web application for browsing and managing dessert recipes.

## Features
- Browse desserts
- Search desserts based on ingredients, occasions, colors, audience, etc
- Clean and simple user interface

## Tech Stack
- React
- JavaScript (ES6)
- HTML/CSS

## Getting Started
1. Clone the repository
2. Run `npm install`
3. Run `npm start`

## Purpose
This project demonstrates frontend development and user-focused content structuring.
